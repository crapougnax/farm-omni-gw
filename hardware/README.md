# Farm Omni Gateway — Hardware Engineering (`hardware/`)

[![License: CERN-OHL-S v2](https://img.shields.io/badge/License-CERN--OHL--S%20v2-blue.svg)](./LICENSE)

This directory contains all open-hardware design files, electronic schematics, PCB layout CAD files, and mechanical enclosure drawings for the **Farm Omni Gateway**.

## 📂 Directory Contents
- `schematics/` — KiCad electronic schematics (.kicad_sch)
- `pcb/` — KiCad board layout, Gerber fabrication files, and drill maps (.kicad_pcb)
- `bom/` — Component purchasing lists, LCSC/Mouser part numbers, and substitution tables
- `mechanical/` — 3D STEP models, laser-cut mounting brackets, and IP67 gland drill templates
